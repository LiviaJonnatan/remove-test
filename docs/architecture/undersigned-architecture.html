Undersigned: the design, and where it stands on 16 October 2026

Read every substantive letter on a rule once, as a batch job, record each argument against the paragraph it concerns, and serve the record. Green runs in main today from one command on a fresh clone. Amber is partly there, and the box says what exists. Faded is not started.

Access. On the VM no port is open to the internet: a browser reaches the page on 3000 and the API's docs on 8000 through gcloud compute ssh -L. On a laptop the same ports are on localhost. 9000 is for developers inspecting ChromaDB. Secrets. .env is git-ignored and the key folder ../secrets/ sits outside the repository; both are injected when a container starts, never baked into an image. No container uses Google Cloud today. DVC runs outside the containers: on the VM it authenticates as the VM's service account, on a laptop with the shared key file. Code. Each Python container also mounts its own src/ over the baked code, so an edit applies without a rebuild. Shaded cells are fetched over the network while running. Everything else is fixed at build or start.
